# My_Agent_ 与主流 Agent 对比（个人向）

> 定位不同：本项目是**单用户、可自托管**的个人副驾，不追求全面超越云端旗舰产品。

| 维度 | My_Agent_ | ChatGPT / Claude 等云端助手 |
|------|-----------|------------------------------|
| 数据驻留 | 默认本地 SQLite，API Key 自管 | 云端账号与策略决定 |
| 工具权限 | 路径 / HTTP 白名单，可审计 NDJSON | 生态插件多，策略因产品而异 |
| 长期记忆 | 自管向量库 + 可删条目 | 产品化记忆，导出/删除能力因版本而异 |
| 会话摘要 | 显式 rolling summary，原文仍留库 | 黑盒上下文管理 |
| 成本可见 | 每请求 token + 估算 USD | 部分产品有用量页 |
| 模型选择 | `.env` + 前端下拉，按请求覆盖 | 订阅档位绑定 |
| 部署 | `make dev` / Docker，单机即可 | 开箱即用，依赖厂商 |
| 多用户 / 协作 | 未做（会话 ID 即边界） | 企业版支持 |

## 本项目亮点（第四周产品化）

1. **透明用量**：流式 `done` 事件与 `/api/usage/stats` 汇总近期消耗。
2. **人格模板**：`data/personas.json` 可版本管理、可扩展。
3. **知识入库**：`POST /api/memory/index-folder` 将 `docs/` 等目录切片进向量记忆。
4. **会话工作台**：侧栏多会话 + 记忆面板，适合长期自用。

## 已知差距

- 无多模态、无大规模插件市场、无协作与权限体系。
- 向量检索为 SQLite + 内存相似度，百万级规模需换专用向量库。
